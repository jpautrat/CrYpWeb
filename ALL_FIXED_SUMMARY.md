## 📝 .env File Editing (Super Easy Now)

### Method 1: Automatic (Easiest)
```
Run: quick_start.bat
→ Notepad opens automatically with .env
→ Edit your keys
→ Save and close
→ Done!
```

### Method 2: Manual
```
1. Find .env file
2. Right-click → Open with Notepad
3. Edit keys:
   KRAKEN_KEY_1=abc123...
   KRAKEN_SECRET_1=xyz789...
   (repeat for 2-5)
4. Save
```

### Important Rules:
- ✅ No spaces around `=`
- ✅ No quotes around values
- ✅ All 5 key pairs required
- ✅ Save before closing

Example:
```ini
KRAKEN_KEY_1=abc123def456
KRAKEN_SECRET_1=xyz789uvw012

KRAKEN_KEY_2=ghi789jkl012
KRAKEN_SECRET_2=mno345pqr678

(etc for keys 3, 4, 5)
```
