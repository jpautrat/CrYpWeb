HOW TO EDIT .env FILE
================================================================================

Easy way:
  1. Run quick_start.bat OR launch.bat
  2. Notepad opens automatically with .env
  3. Edit your API keys
  4. Save and close

Manual way:
  1. Find: .env
  2. Right-click → Open with → Notepad
  3. Find: KRAKEN_KEY_1=YOUR_API_KEY_HERE
  4. Replace with your actual key
  5. Repeat for keys 2, 3, 4, 5
  6. Save

Example .env format:
  KRAKEN_KEY_1=abc123def456...
  KRAKEN_SECRET_1=xyz789uvw012...
  
  (NO spaces around =)
  (NO quotes around values)
